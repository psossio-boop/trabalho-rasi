# Trabalho Prático - Containerização com Docker e Flask
**Disciplina:** Redes e Administração de Sistemas (RASI)  
**Instituição:** IFSP - Câmpus Campos do Jordão  

## 📌 Descrição do Projeto
Este repositório contém a implementação de uma aplicação web desenvolvida em Python com o framework Flask, containerizada através do Docker utilizando a imagem oficial `python:3.14-slim`.

## 📁 Estrutura de Ficheiros
* `app.py` - Aplicação Python com 3 rotas (`/`, `/sobre`, `/contato`).
* `Dockerfile` - Ficheiro de instruções do Docker.
* `requirements.txt` - Dependências do projeto (`flask`).
